# 扩展包：SAO~气息遮断魔法陷阱 Ⅱ

- 引擎：RPG Maker MV 1.6.1，NW.js 0.96。
- 用法：读档进入任意地图，站着不动、不在对话中时按 F8。插件会自己切换到各个回想房间。
- 录制范围：4 个回想房间（Map081–084）里的回想，按房间、从上到下、从左到右排序。当前版本数据：155 段回想，共 172 个录像（跳过 4 段战斗回想）。

## 做了什么

| 步骤 | 实现 |
| --- | --- |
| 列出回想 | 读 `www\data\Map081–084.json`，有“放弃回顾”选项的事件就是一段回想 |
| 选哪个 | 每个“仅限事件”（含（一）（二）（三））各录一个；没有时录“包含录音 / 仅有录像”两个；再没有时录“完整剧情” |
| 跳过 | 选项里有“进入战斗”的回想（含“情欲值低 / 中 / 高”那两段，它们也是战斗） |
| 解锁 | 直接执行回想 NPC 带选项的那一页，不检查页条件；同时临时打开开关 81–84（第N篇回想解锁），不花“不安总量” |
| 启动 | 切换到该回想所在房间，空闲后 `$gameMap._interpreter.setup(page.list, eventId)` |
| 播放中 | 打开游戏自带的 `POR_AutoSkipMessage` 自动翻页；回想菜单选目标项，剧情里的其他选项选第一项 |
| 结束 | 回到回想房间并空闲 0.75 秒；或者停在其他地图、没有事件运行 8 秒 |
| 强制结束 | 清掉事件和对话、图片、色调，切回回想房间 |
| 会话结束 | 还原开关 81–84 和剧情变量（100），回到按 F8 时的位置 |

**录完不要存档，直接关闭游戏。** 回放剧情会改动大量开关和变量；核心默认在会话开始后拦截所有存档写入。

输出文件名：`<序号3位>_<日期和标题>[_选项].mp4`，例如 `001_5-31序章.mp4`、`018_6-11晚上与亚丝娜分开后狩猎怪鸽和守卫树屋_仅限事件(一).mp4`。
